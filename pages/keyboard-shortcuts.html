Betterbird keyboard shortcuts

The keys you will use most. Ctrl+N means hold Ctrl and press N.

Mail

New messageCtrl+N or Ctrl+M
ReplyCtrl+R
Reply allCtrl+Shift+R
ForwardCtrl+L
Get new messagesF5 (all accounts: Shift+F5)
Search all mailCtrl+K
Find in the messageCtrl+F
Next unread messageN
Mark as read / unreadM
Star (flag)S
ArchiveA
DeleteDel
Open the address bookCtrl+Shift+B
PrintCtrl+P
ReThread mode (Betterbird only)Ctrl+T, then arrow keys to pick the new parent and Ctrl+T again; Esc to leave

Writing a message

Send nowCtrl+Enter (send later: Ctrl+Shift+Enter)
Bold / Italic / UnderlineCtrl+B / Ctrl+I / Ctrl+U
Insert a linkCtrl+K
Larger fontCtrl+> or Ctrl+.
Smaller fontCtrl+< or Ctrl+,
Paste without formattingCtrl+Shift+V
Check spellingCtrl+Shift+P

Address book

New contactCtrl+N
Write to the selected contactsCtrl+M
Quick filterCtrl+F
Advanced searchCtrl+Shift+F
